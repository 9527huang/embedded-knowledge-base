# 知识审核清单

## 来源可靠性

- [ ] 是否有原始来源。
- [ ] 是否优先查过官方文档、标准或数据手册。
- [ ] 是否记录版本、日期和适用对象。

## 内容正确性

- [ ] 关键结论是否可验证。
- [ ] 是否标明适用条件和例外情况。
- [ ] 是否区分事实、推论和个人经验。
- [ ] 是否存在与其他笔记冲突的地方。

## 表达质量

- [ ] 是否用自己的话解释清楚。
- [ ] 是否给出工程场景。
- [ ] 是否包含常见错误。
- [ ] 是否能被未来的自己快速复用。

## 追溯记录

- [ ] 是否更新 `CHANGELOG.md`。
- [ ] 是否建立来源记录。
- [ ] 是否链接相关主题或项目笔记。
