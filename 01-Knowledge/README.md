# Knowledge

这里存放已经核查、改写并可复用的正式知识笔记。

建议主题：

- `c-language/`: C 语言、编译、链接、内存模型、常见缺陷。
- `arm/`: ARM 架构、启动流程、中断、异常、汇编、CMSIS。
- `hardware/`: 原理图阅读、接口电路、EMC、电源、采样和保护。
- `freertos/`: 任务、调度、队列、信号量、中断协作、性能分析。
- `canopen/`: 对象字典、PDO、SDO、NMT、SYNC、EMCY、CiA 规范。
- `ai/`: AI 工具链、提示词、代码辅助、知识库自动化。
- `plc/`: PLC 基础、通信、控制逻辑、现场调试。
- `servo-debugging/`: 伺服参数、运动控制、报警分析、调试流程。
