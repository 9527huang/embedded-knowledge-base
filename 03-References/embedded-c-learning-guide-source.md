## 核心内容摘要

该资料以嵌入式软件开发为背景讲解 C 语言，强调从内存、函数架构和编译器三个视角理解 C。内容包括 Ubuntu/Vim/GCC/GDB 环境、编译过程、预处理、关键字、运算符、函数、C 语言中的面向对象思想、SOLID 原则、内存模型、指针和数组。

## 关键结论

- 嵌入式 C 学习不能停留在语法层面，应结合内存映射、编译链接和工程架构理解。
- GPIO、UART、I2C 等外设控制在软件视角上本质是访问内存映射寄存器。
- `volatile`、宏、`__attribute__` 等编译器相关机制是嵌入式 C 的重点。
- 指针、数组、栈、堆、全局区、代码段等内存概念是排查工程问题的基础。
- C 语言也可以通过结构体、函数指针、弱符号、回调和接口分层实现一定的架构设计。
